# Changelog

## 5.3 — current release

- Playlist rotation across multiple videos
- Shuffle on unlock: a new video every time you unlock
- Per-video loop / play-once / auto-advance control
- Per-video mute and unmute
- Custom fit and scale: Fit, Crop, Stretch, Fill
- In-app preset library of optimized looping wallpapers
- Battery-smart rendering that pauses when the screen locks

## Earlier versions

- 5.0–5.2 — internal builds distributed through the author's portfolio page. The 5.3 release above is the current public build.
